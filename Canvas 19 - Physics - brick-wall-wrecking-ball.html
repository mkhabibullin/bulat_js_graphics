Knock down a wall with just two rules

Every brick is a solid box with a matrix: which way it is turned, and where its middle is. The whole program follows two rules:
Rule 1: no corner of a brick may be inside another brick.
Rule 2: a push that does not go through a brick's middle also turns it (push a book near its edge and it spins).

The yellow brick's matrix


    

        Each column is the direction of one side of the brick, and the
        orange column is the middle of the brick.

How does Rule 1 work?

    

        Is a corner inside a turned brick? That is hard to see. So we look at the corner
        from the brick's own point of view: we undo the brick's matrix. For a turn, undoing
        is easy: the columns become rows. Now the brick is a simple box around (0, 0, 0),
        and the corner is inside if |x|, |y| and |z|
        are all smaller than half the brick's size. If it is inside, we push the bricks apart.
        Turn on "Show skeleton" to see the corners and each brick's three matrix directions.
    


    
What does the mortar do?

    

        Every brick sleeps (stays perfectly still) until it comes loose. A brick comes loose when:

        1. something hits it hard enough. Mortar holds it, so with mortar the hit must be harder;

        2. the bricks holding it up move away. Without mortar it falls if any brick under it moves;
        with weak mortar only if all of them move; strong mortar keeps it in place, even over a hole.

        "Show skeleton" draws white lines from each sleeping brick to the bricks holding it up.
    


    
Try it yourself

    

        Open this file in an editor and find wall and wallPlan:

        1. Build a taller wall: change rows: 7 to rows: 10.

        2. Build a pyramid: change the line that starts with const pieces to
        const pieces = Array(wall.bricksPerRow - row).fill(1);

        3. Build a crossed tower. Replace the whole for loop in wallPlan with:

        for (let row = 0; row < 10; row++) { const turn = row % 2 === 0 ? 0 : 90; for (const side of [-16, 16]) { plan.push(turn === 0 ? { x: 0, y: 16 + row * 32, z: side, turn, size: 1 } : { x: side, y: 16 + row * 32, z: 0, turn, size: 1 }); } }

        The turn uses a rotation matrix to place each brick.

        4. Harder: change brickMass to make the bricks heavier or lighter, and see how far they fly.
    


    

        Real bricks have rough edges and real mortar is uneven, so a real wall breaks a little less neatly.
