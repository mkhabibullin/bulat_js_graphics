Shadows: a matrix that flattens the world

The one rule: a shadow is the same cube, with one more matrix.
shadow of cube = shadowMatrix × cubeMatrix

The shadow matrix


        

        

            
Follow the orange corner

            

        

    


    

        The orange row is all zeros, so every height becomes 0 and everything lands on the floor.
        Drag the picture to look around.
    


    
The big question

    

        Tick "Hide the cube", put the Sun at 90°, and move "Lift cube". The shadow never changes!
        So from the shadow alone, can you say how high the cube is? No: the matrix threw the height away,
        and no other matrix can bring it back. A photo loses depth in the same way.
    


    
Try it yourself

    

        1. With a real box and a torch: can you make a six-sided shadow?

        2. Open this file in an editor and change the first row of makeShadowMatrix to [2, sunX, 0, 0]. What happens to the shadow?

        [3, 2, 8], [2, 6, 8], [6, 7, 8], [7, 3, 8],

        The shadow gets a roof too, and you did not change the shadow code at all!
