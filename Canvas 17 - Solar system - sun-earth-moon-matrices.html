Try it yourself

    

        Open this file in an editor and find buildSolarSystem:

        1. Give the Moon a satellite. Add this line to the list of bodies:

        { name: 'Satellite', matrix: multiplyMatrices(moon, orbit(moonAngle * 3, 25)), radius: 4, color: '#f472b6' },

        2. Add a planet that only follows the Sun:

        { name: 'Venus', matrix: orbit(earthAngle * 1.6, 170), radius: 20, color: '#fb923c' },

        3. Tilt the Moon's circle. Change its line to:

        const moon = multiplyMatrices(earth, multiplyMatrices(rotationX(0.5), orbit(moonAngle, 70)));

        4. Harder: give Venus a moon of its own.
